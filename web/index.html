How this page works

500 characters per request. Longer scripts are split at sentence boundaries and each chunk is sent to the public Murf widget endpoint.

One MP3. The chunks are joined at frame level and returned as a single file. ID3 data is dropped from later chunks to avoid gaps.

Premium voices. The catalog includes V… voices the widget hides. They are labeled premium and may disappear if Murf changes the endpoint.

Shared budget. The public endpoint has a per-IP call budget. This page limits each browser's chunk usage, but a busy deploy can still hit Murf's ceiling.
